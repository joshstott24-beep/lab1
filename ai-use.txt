How AI helped:
I had already written most of the code while following the lecture. I used Claude to review it one file at a time against the assignment. It also explained how the Bootstrap grid classes (row, col-12, col-md-7, and col-md-5) make the form responsive, so I could understand the code I was submitting.

Suggestion I revised:
My original styles.css had its own CSS grid layout for the form, plus custom styles for headings, inputs, buttons, and tables. After adding the Bootstrap grid to request-form.html, these rules conflicted with it. The original CSS also had an invalid color value (fffff). I revised the stylesheet so it only handles basic typography, spacing, and colors while Bootstrap handles the responsive layout.
